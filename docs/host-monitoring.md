# 主机 IP 详情监控

主机管理列表中的公网 IP、内网 IP 在用户拥有 `hosts/terminal` 权限时可打开主机详情标签。列表标签保持挂载，因此筛选条件、分页、排序和滚动位置会在详情与列表之间切换时保留。

## 监控范围

- 首版通过现有 SSH 连接支持 Linux 主机；Windows 主机保留资产信息，并在详情页提示监控与容器暂不支持。
- 主机详情顶部提供“时间颗粒度”选择，支持 10s、15s、20s，默认 10s；主机指标每次采集完成后按所选间隔刷新。切换间隔保留现有快照和曲线，并重设下一次采集时间；请求进行中切换间隔不会重复发起请求。容器独立间隔 30 秒刷新，两者均不重叠请求，慢 Docker 不会阻塞主机数据展示和下一轮采集。页面隐藏、离开详情页、锁屏、注销或组件卸载时停止请求并清理监听器。
- 自动刷新及“立即刷新”保留当前数据，不显示按钮转圈或遮罩；响应到达后直接更新指标和曲线。返回列表可点击工作区的“主机列表”标签。
- 主机请求最多等待 20 秒，容器请求最多等待 25 秒；超时保留上次成功数据并提示错误，不锁住其他页面操作。
- 仪表盘等待首次数据时保留稳定的进度环结构并展示 `--`；图表按不可变配置浅监听、延迟绘制，不在每次响应式更新中深度遍历和同步强制重绘。
- 前端只保留当前主机最近 15 分钟、最多 90 个采样点，不写入历史数据库，也不依赖 Prometheus 或 Grafana。
- 监控包含 CPU、内存、根文件系统、网络吞吐、负载、Swap、系统信息、DNS、SSH 端口、TCP 拥塞控制、IPv4/IPv6 与 BBR 状态。
- SSH 探测失败显示错误状态；可选字段读取失败使用稳定的空值或 `-`，不会伪造核心监控数据。

## 容器

- 容器列表、启动、停止、重启和日志接口均要求 `hosts/terminal` 权限，并通过后端校验容器标识，不接受任意 Shell 命令。
- 启动、停止、重启需要二次确认；操作成功后刷新列表，失败时保留当前页面状态并显示错误。
- 日志默认读取最近 200 行，允许范围为 1 到 1000 行，响应最大 1 MiB；Docker 不存在、无权限或守护进程不可用时显示“容器服务不可用”。
- “进入终端”复用现有个人终端页面，以居中的 980×720 独立弹窗打开，不进入全量终端；不同主机和容器使用独立窗口，重连保留容器上下文。浏览器拦截弹窗时提示允许弹窗，不切换当前页面。后端生成经过校验的 `docker exec` 命令；容器操作和日志读取写入现有终端审计与操作日志。

## 手动验收

1. 在主机管理列表点击 IP，确认详情标签打开且列表筛选和分页可恢复。
2. 确认仪表盘、最近 15 分钟曲线、系统信息和磁盘表格正常更新；离开页面后不再产生轮询请求。
3. 在具备 Docker 的 Linux 主机上确认容器操作需要确认、操作后刷新、日志可关闭；进入终端打开个人终端弹窗而非全量终端，重连仍进入原容器，关闭弹窗不影响主机详情及监控。
4. 在无终端权限、Windows 主机、SSH 失败和 Docker 不可用场景确认页面显示降级状态而非伪造数据。
