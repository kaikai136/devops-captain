# 暗色模式颜色约定

通用面板、列表、工具栏、表格和表单使用 `--ui-card`、`--ui-muted`、`--ui-border`、`--ui-foreground` 与 `--ui-muted-foreground`。不要为这些区域固定白色背景或深蓝色文字。半透明面板使用 `color-mix()` 混合主题表面色与透明色。

`html.dark` 驱动全局主题变量，包含挂载到 `body` 的弹窗、下拉菜单和提示。工作区内继续保留 `.workspace-dark`，用于导航和页面级专用样式；两者使用同一套基础色。

Element Plus 的标签、提醒和状态组件通过 `--el-color-*-light-*` 混合主题表面色，避免暗色模式仍出现浅色状态底色。主机验证状态、平台标签和 IP 标签保留各自语义色，文字亮度适配暗色背景。

二维码、用户上传的品牌图片、终端主题和登录/锁屏插画不是通用面板，不做反色滤镜或统一覆盖。二维码需保留黑白对比与留白。

回归检查：浅色和暗色下分别检查展开/折叠菜单、主机表格、账户/用户/角色/设备列表、批量执行、应用市场、个人中心、系统设置、网络与安全工具，以及弹窗、下拉菜单、校验错误、悬浮和禁用状态。

自动验证：在 `frontend` 执行 `npm run test:run` 和 `npm run build`。`src/styles/__tests__/darkMode.structure.test.ts` 防止主要业务样式重新引入固定白色表面和深色正文。
