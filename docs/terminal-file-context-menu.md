# 全量终端文件右键菜单

文件项右键菜单采用参考图的 256px 窄型菜单，顶部横排剪切、复制、粘贴、重命名、删除；主体按打开、预览、内置编辑器、刷新、上传、下载、移动、复制信息、终端、属性分组。文件列表空白处保留适用操作和新建入口。无 AI 功能；主菜单和子菜单均跟随系统主题。

## 文件操作

- 剪贴板只保存在当前应用内存中，支持同一服务器跨目录、跨终端标签，不写入系统剪贴板，也不支持跨服务器粘贴。
- 文件“复制”与“复制信息”不同，后者只向系统剪贴板写入路径或名称。
- 复制后可继续粘贴；剪切只在移动成功后清空，失败、取消覆盖、切换标签不会丢失剪贴板。
- “移动到”使用路径输入弹窗，可输入绝对目录、`~` 或当前目录的相对路径。目标目录必须已经存在。
- 同名目标返回 `409/file_exists`，明确确认后才覆盖。同名目录合并并保留目标独有文件；文件、目录、符号链接类型不一致时拒绝。
- 符号链接作为链接复制，不遍历目标。禁止根目录、原位置、源目录内部或源/目标交叠的操作。
- 通过 SFTP 在目标目录暂存完整内容，原目标移至临时备份后发布。移动时保留源备份，整批发布失败会尝试恢复。无法回滚或清理时返回具体备份路径，不静默丢弃备份。
- 不提供针对应用外写入程序的文件锁。操作期间请勿同时修改涉及的远端源/目标目录；大目录需要暂存空间。

## 上传

- 上传文件：现有单文件上传流程。
- 上传文件夹：保留选中文件夹本身，例如 `folder/nested/a.txt`。
- 上传文件夹内容：只去掉最外层目录，例如 `nested/a.txt`，不将内部层级拍平。沿用浏览器文件夹选择器和现有上传传输记录；不新增空目录上传。

## 接口与部署

新增 `POST /api/web-terminal/hosts/{hostId}/files/transfer/`，JSON 参数为 `paths`、`targetDirectory`、`operation`（`copy`/`move`）、`overwrite`（布尔值，默认 `false`）。最多选择 200 个源路径。成功返回 `items` 和可能的清理 `warnings`；常见失败码包括 `file_exists`、`file_type_conflict`、`source_not_found`、`permission_denied`、`invalid_destination`、`rollback_failed`。

接口沿用终端权限检查，并审计成功或失败的源/目标操作。新增审计 `copy`、`move` 类型，部署后执行：

```sh
cd backend
python manage.py migrate
```

迁移 `0006_file_copy_move_audit` 只更新审计字段的可选值，不改动现有审计记录。上传、下载以及编辑器保存冲突接口保持不变。
